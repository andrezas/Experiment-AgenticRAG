# Architecture Decision Records (ADRs)

Este diretório contém os Registros de Decisão de Arquitetura (ADRs) para o projeto. Um ADR é um documento que captura
uma decisão arquitetural importante feita juntamente com seu contexto e consequências.

Para mais informações sobre o formato, veja
[Michael Nygard's framework](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions).

## Status dos ADRs

- **Proposto:** A decisão está sendo discutida e ainda não foi aceita.
- **Aceito:** A decisão foi tomada e a equipe deve segui-la.
- **Depreciado:** A decisão foi substituída por um ADR posterior.
- **Rejeitado:** A decisão foi proposta, mas não foi aceita.
